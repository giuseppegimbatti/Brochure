BROCHURE SFOGLIABILE 24x24 - GITHUB PAGES

1. Crea un repository pubblico su github.com.
2. Carica index.html, brochure-24x24.pdf e la cartella pages con le nove immagini.
3. In Settings > Pages scegli Deploy from a branch, branch main, folder /(root), poi Save.
4. Il link sara https://TUO-UTENTE.github.io/NOME-REPOSITORY/

Importante: mantieni i nomi dei file e la cartella pages.
